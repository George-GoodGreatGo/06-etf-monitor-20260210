# 计划：Score 视图阈值背景带（动量程度）

## 1. Summary
- 仅针对 `MA50归一视图（Score走势）` 增加背景阈值区间色带，用颜色表达动量程度。
- 按已确认的互斥区间渲染（第3条纠偏为 `< -20`）：
  - `[-10, 0]`：淡绿色
  - `[-20, -10)`：深绿色
  - `< -20`：更深绿色
  - `(0, 10]`：浅黄色
  - `(10, 20]`：浅橙色
  - `> 20`：红色
- 不改后端数据与口径，仅改前端图表可视化。

## 2. Current State Analysis
- `src/components/charts/RpsStyleChart.tsx` 已支持 `viewMode='score'`：
  - 主线：`scorePct`
  - 基线：`y=0` 虚线
- 当前图表背景为统一深色底（`layout.background`），尚无按数值区间的背景分层。
- 该组件已具备多系列管理与边界锁定逻辑，适合通过“额外系列”叠加色带，不影响现有主线。

## 3. Proposed Changes

### 3.1 在 score 视图增加阈值背景带
- 修改文件：`src/components/charts/RpsStyleChart.tsx`
- 实现方式：
  - 在 `viewMode==='score'` 时，新增一组“背景带系列”（推荐 `AreaSeries` 或 `BaselineSeries` 组合）并放在主线下方。
  - 每个阈值区间生成一个覆盖全时间轴的数据带，仅用于背景着色：
    - 带体颜色低透明度（建议 `alpha 0.12~0.20`），避免压过主线。
  - 非 score 视图不渲染这些背景带。

### 3.2 区间与颜色映射（固定）
- 区间定义（互斥、覆盖）：
  - `x < -20`：更深绿色
  - `-20 <= x < -10`：深绿色
  - `-10 <= x <= 0`：淡绿色
  - `0 < x <= 10`：浅黄色
  - `10 < x <= 20`：浅橙色
  - `x > 20`：红色
- 颜色建议（可按视觉微调）：
  - 更深绿：`rgba(22, 101, 52, 0.18)`
  - 深绿：`rgba(21, 128, 61, 0.16)`
  - 淡绿：`rgba(74, 222, 128, 0.14)`
  - 浅黄：`rgba(250, 204, 21, 0.14)`
  - 浅橙：`rgba(251, 146, 60, 0.14)`
  - 红色：`rgba(239, 68, 68, 0.16)`

### 3.3 图例与可读性增强（轻量）
- 修改文件：`src/components/charts/RpsStyleChart.tsx`
- 在 `score` 视图图例区域追加“阈值颜色说明”短文本（不新增复杂控件）：
  - 示例：`<-20 深绿 | -20~-10 绿 | -10~0 浅绿 | 0~10 黄 | 10~20 橙 | >20 红`
- 保持现有 hover、ticker 开关、缩放拖拽行为不变。

## 4. Assumptions & Decisions
- 已确认第3档为 `< -20`（不是 `< 20`）。
- 色带仅在 `score` 视图显示；`raw/relative` 不显示。
- 阈值为固定常量，不加用户可配置项，避免过度复杂化。

## 5. Verification Steps
- 视觉验证：
  - 切换到 score 视图，背景出现 6 段阈值色带；
  - 切到 raw/relative，色带消失。
- 口径验证：
  - `y=0` 基线仍可见；
  - 曲线与 hover 数值不变（只增强背景，不改数据）。
- 交互验证：
  - ticker 开关、滚轮缩放、轴拖拽缩放、边界锁定行为保持正常。
- 工程验证：
  - `npm run build` 通过；
  - `RpsStyleChart.tsx` 无新增诊断错误。
