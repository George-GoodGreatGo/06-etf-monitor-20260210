# 计划：大盘看板副图顺序与主图线段规则说明改造

## 1. Summary
- 目标：
  - 将“股债性价比（分位）”副图下移到最底部，与“独家流动性指数（5年分位）”位置对调。
  - 主图线段放弃旧的 `v5(3指标)` 色彩规则，改为：
    - `独家流动性指数（5年分位） >= 80` -> 主图线段红色（过热）。
    - `股债性价比分位 >= 90` -> 主图线段绿色（极致性价比）。
  - 在图表上方新增规则说明区（参考低波机会模块说明区域）。
- 已确认决策：
  - 同时触发时：绿色优先。
  - 未触发时：保持默认蓝色主线。

## 2. Current State Analysis
- 目标文件：`src/components/charts/MarketLiquidityChart.tsx`。
- 当前主图色段逻辑：
  - 基于 `v5>=70` 生成红段（`hsHotSegments`），基于 `v5<=30` 生成绿段（`hsColdSegments`）。
  - 该逻辑与新规则不一致（新规则改看 `v5Pct` 与 `ebPct`）。
- 当前副图顺序：
  - 顺序为：`独家流动性指数（3指标）` -> `股债性价比（分位）` -> `独家流动性指数（5年分位）`。
  - 需改为：`独家流动性指数（3指标）` -> `独家流动性指数（5年分位）` -> `股债性价比（分位）`。
- 当前图表上方：
  - 仅有开关按钮与 hover 信息，没有独立“规则说明块”。

## 3. Proposed Changes

### A. 主图线段规则改造（按 v5Pct / ebPct）
- 文件：`src/components/charts/MarketLiquidityChart.tsx`
- 变更：
  - 移除旧的 `hsHotSegments/hsColdSegments` 生成逻辑（`v5>=70`、`v5<=30`）。
  - 新增主图分段生成：
    - 当 `ebPct >= 90`：归类为绿色段（优先级最高）。
    - 否则当 `v5Pct >= 80`：归类为红色段。
    - 其他：不生成着色段，保留默认蓝色主线。
  - 渲染层仅绘制红段/绿段两类覆盖线（覆盖默认蓝线）。
- 原因：
  - 与你指定的新规则一致，并满足“绿色优先”决策。

### B. 副图顺序对调
- 文件：`src/components/charts/MarketLiquidityChart.tsx`
- 变更：
  - JSX 中将两个 pane 的渲染顺序由
    - `股债性价比分位` 在前、`流动性5年分位` 在后
  - 调整为
    - `流动性5年分位` 在前、`股债性价比分位` 在后（股债在最下）。
  - 保持开关按钮与 show/hide 逻辑不变。
- 原因：
  - 满足“股债性价比副图放最下”的展示要求。

### C. 图表上方新增规则说明区
- 文件：`src/components/charts/MarketLiquidityChart.tsx`
- 变更：
  - 在按钮区下方新增“规则说明”块（风格参考低波机会说明区）：
    - 绿色：`股债性价比分位 >= 90`，主图线段标记绿色（极致性价比）。
    - 红色：`流动性5年分位 >= 80`，主图线段标记红色（流动性过热）。
    - 同时触发：绿色优先。
  - 文案说明“未触发时主图保持默认蓝色”。
- 原因：
  - 强化规则可解释性，减少用户误读。

## 4. Assumptions & Decisions
- 已确认：
  - 颜色优先级：绿色优先于红色。
  - 未触发颜色：保持默认蓝色。
- 不变项：
  - 分位计算口径（5年）不变。
  - 阈值线显示（20/80）不变。
  - 后端数据接口与字段结构不变。

## 5. Verification Steps
- 静态检查：
  - 运行 `npm run check`，确保类型与编译通过。
- 视觉与交互验证：
  - 副图顺序为：3指标 -> 5年分位 -> 股债分位（最下）。
  - 图表上方可见规则说明区，文案与阈值正确。
  - 主图线段着色规则：
    - `ebPct>=90` 出现绿色段；
    - `v5Pct>=80` 出现红色段；
    - 同日双触发时显示绿色段；
    - 其他区间仅显示默认蓝色主线。
- 回归验证：
  - hover、联动、缩放与其它指标线显示逻辑保持正常。
