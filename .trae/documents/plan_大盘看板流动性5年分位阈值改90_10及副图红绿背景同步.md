# 计划：大盘看板流动性5年分位阈值改为90/10并同步副图红绿背景

## 1. Summary
- 目标：
  - 将“独家流动性指数（5年分位）”过热阈值从 `>=80` 调整为 `>=90`。
  - 对应地将该副图阈值体系调整为：
    - 过热区：`>=90`（红色背景）
    - 低位区：`<=10`（绿色背景）
  - 主图线段红色触发条件同步从 `v5Pct>=80` 调整为 `v5Pct>=90`。
- 范围：
  - 主要改动 `src/components/charts/MarketLiquidityChart.tsx`；
  - 同步更新 `src/components/MarketLiquidityPanel.tsx` 的说明文案，避免口径不一致。

## 2. Current State Analysis
- 当前主图规则（已在 `MarketLiquidityChart`）：
  - 绿色：`ebPct>=90`
  - 红色：`v5Pct>=80`
  - 同日双触发：绿色优先
- 当前流动性5年分位副图阈值：
  - 阈值线绘制为 `20/80`
  - 红绿背景分区按 `>=80`、`<=20` 渲染（`updateV5PctZoneBg`）
- 当前规则说明文案：
  - 图表上方规则区写的是“流动性5年分位 >=80”
  - 面板文案 `MarketLiquidityPanel` 仍写“≤20 偏机会，≥80 偏风险”

## 3. Proposed Changes

### A. 主图着色规则阈值回调（80 -> 90）
- 文件：`src/components/charts/MarketLiquidityChart.tsx`
- 变更：
  - 在主图分段分类逻辑中，将红色条件从 `v5Pct>=80` 改为 `v5Pct>=90`。
  - 绿色优先、默认蓝色保持不变。
- 原因：
  - 与新规则“流动性过热阈值>=90”一致。

### B. 5年分位副图阈值线与背景区改为90/10
- 文件：`src/components/charts/MarketLiquidityChart.tsx`
- 变更：
  - `v5Pct` 副图 `createPriceLine` 从 `20/80` 改为 `10/90`。
  - `updateV5PctZoneBg()` 中坐标阈值从 `y20/y80` 改为 `y10/y90`。
  - 红绿背景色保持现有风格（红：过热，绿：低位），仅改变触发分界。
- 原因：
  - 使副图视觉阈值与主图规则一致，并满足“>=90 / <=10”的要求。

### C. 规则说明文案同步
- 文件：`src/components/charts/MarketLiquidityChart.tsx`
- 变更：
  - 图表上方规则说明中的红色条件文案从 `>=80` 改为 `>=90`。
- 文件：`src/components/MarketLiquidityPanel.tsx`
- 变更：
  - 面板说明“独家流动性指数（5年分位）”文案从“≤20 偏机会，≥80 偏风险”改为“≤10 偏机会，≥90 偏风险”。
- 原因：
  - 避免图表规则与页面说明不一致。

## 4. Assumptions & Decisions
- 已确认：
  - “流动性过热”阈值改为 `>=90`。
  - “流动性低位”阈值改为 `<=10`。
- 不变项：
  - 股债性价比分位绿色条件仍为 `>=90`（主图绿色优先）。
  - 5年分位计算口径（1260/630）不变。
  - 图表布局与交互（hover/联动/开关）不变。

## 5. Verification Steps
- 静态检查：
  - 运行 `npm run check`，确保类型与编译通过。
- 图表行为验证：
  - 主图红段仅在 `v5Pct>=90` 出现；
  - 主图绿段仍在 `ebPct>=90` 出现，且与红色冲突时绿色优先；
  - 副图阈值线显示为 `10/90`；
  - 副图背景红区对应 `>=90`，绿区对应 `<=10`。
- 文案一致性验证：
  - 图表上方规则区显示 `>=90`。
  - 大盘看板说明文案显示“≤10 偏机会，≥90 偏风险”。
