# 页面设计说明（桌面端优先）

## 全局（适用于所有页面）
### Layout
- 桌面端优先：内容最大宽度 1200px，居中；左右留白随屏幕增大而增加。
- 栅格：列表区使用 CSS Grid（表头+行）或表格组件；筛选区使用 Flexbox。
- 响应式：
  - ≥1024px：筛选条与列表同屏；
  - <1024px：筛选折叠到可展开面板；列表改为卡片式两列/一列。

### Meta Information（通用默认）
- title 模板：`ETF 监测 - {页面名}`
- description：突出“Top100、筛选排序、Z 值标记、仅完整交易日数据”。
- Open Graph：og:title / og:description / og:type=website。

### Global Styles（Design Tokens）
- 背景色：#0B1220（深色） / 内容卡：#111B2E
- 文字：主文字 #E6EDF7，次级 #A9B6CC
- 强调色：正向 #22C55E，警示 #F59E0B，危险 #EF4444
- 字体：系统字体栈；字号梯度 12/14/16/20/24
- 按钮：
  - Primary：强调色填充；hover 提升亮度；disabled 降低不透明度。
  - Link：下划线仅 hover 显示。
- 表格/卡片：行 hover 提高对比度；选中态展示左侧强调条。

## 1）首页（Top100 列表）
### Meta
- title：ETF 监测 - Top100
- description：Top100 ETF 列表，支持筛选、排序与 Z 值标记，仅展示完整交易日数据。

### Page Structure
- 顶部导航（固定或随滚动收起）
- 筛选/排序工具条
- 数据状态条（更新时间、最新完整交易日、API 状态）
- Top100 列表（表格/卡片）
- 页脚（方法说明入口、免责声明简述）

### Sections & Components
1. 顶部导航（NavBar）
   - 左侧：站点 Logo/名称
   - 右侧：导航链接：Top100、数据与方法
2. 筛选与排序工具条（FilterBar）
   - 关键字输入：占位“代码/名称”
   - 类别选择（如有）：下拉
   - 排序选择：下拉（Z 值、最新交易日、关键指标）+ 升/降切换
   - 重置按钮：清空筛选并恢复默认排序
3. 数据状态条（DataStatusBanner）
   - 显示：最近一次成功拉取时间、当前展示的“最新完整交易日”
   - 错误态：API 失败时展示红色条幅 +“重试”按钮
   - 完整性提示：若部分 ETF 数据不完整，展示黄色提示“已剔除/降权不完整数据（不补全）”
4. Top100 列表（TopTable）
   - 表头列：代码、名称、最新交易日、关键指标、Z 值、状态
   - 行点击：进入详情页；保持筛选/排序（URL query 或本地状态）
   - Z 值标记（ZBadge）：
     - 高：Z≥2（红/紫）
     - 中：1≤Z<2（橙）
     - 低：Z<1（灰/绿）
     - 缺失：显示“—”，并以淡色提示“不可用”
   - 状态列：
     - complete：正常
     - incomplete：显示“数据不完整”，该行 Z 值/排名不展示或置灰
     - api_error：显示“拉取失败”，禁止显示任何推测值

## 2）ETF 详情页（占位）
### Meta
- title：ETF 监测 - {ETF代码}
- description：ETF 详情（建设中），展示基础信息与后续模块占位。

### Page Structure
- 顶部导航
- 面包屑/返回（返回 Top100，保留筛选排序）
- 基础信息卡
- 指标模块占位区（若数据缺失则明确提示）

### Sections & Components
1. 返回与标题（Header）
   - 返回按钮：“← 返回 Top100”
   - 标题：`{code} {name}`
2. 基础信息卡（InfoCard）
   - 字段：最新完整交易日、当前 Z 值（若不可用显示“—”）
3. 占位模块（PlaceholderCards）
   - 卡片标题：如“走势”、“资金流”、“更多指标”（仅占位，不实现）
   - 内容：文案“模块占位，后续上线”
4. 数据约束提示（IntegrityNote）
   - 固定文案：仅展示完整交易日数据；缺失/失败不补全、不杜撰。

## 3）数据与方法说明页
### Meta
- title：ETF 监测 - 数据与方法
- description：说明数据来源、完整交易日口径与 Z 值定义，强调不补齐、不杜撰。

### Page Structure
- 顶部导航
- 单列正文（Markdown 风格排版）
- FAQ 折叠面板

### Sections & Components
1. 说明正文（Content）
   - 数据来源：明确“通过外部 API 获取”
   - 更新频率：以“最近成功拉取时间”为准
   - 完整交易日规则：列出校验点（字段齐全/校验通过）
   - Z 值定义：公式 + 历史窗口口径（以产品实际实现为准）
2. FAQ（Accordion）
   - “为什么有些 ETF 不显示 Z 值？”
   - “API 失败时为什么不显示估算值？”
3. 免责声明（FooterNote）
   - 仅信息展示，不构成投资建议。
