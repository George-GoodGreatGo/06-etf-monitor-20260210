# 沉浸式大师语录首页 Spec

## Why
当前登录后的默认落地页以数据面板为主，信息密度高，缺少“理性、耐心、冷静、周期”这类长期投资心智的沉浸式入口。新增一个以投资大师语录为核心的首页，作为登录后第一眼看到的内容，帮助用户快速进入正确的投研心态。

## What Changes
- 新增一个沉浸式首页（登录后默认落地页），展示巴菲特、查理·芒格、霍华德·马克思的经典语录轮播（中文、英文、出处、时间）。
- 首页视觉风格参考苹果官网产品详情页：极简、强聚焦、大字号排版、留白、暗色沉浸背景、微动效（淡入/视差/进度指示等）。
- 现有数据面板页从根路径迁移到新路径（例如 `/market`），并保持原有查询参数 `?tab=` 行为不变。
- 左侧导航新增“首页”入口，并将原先的“ETF200 列表 / AI 解读 / 大盘看板 / 低波机会”导航改为指向迁移后的数据面板页（仍保留 tab 维度）。
- 为兼容旧链接：访问 `/?tab=...` 时自动跳转到 `/market?tab=...`。
- **BREAKING**：根路径 `/` 不再展示原数据面板内容（改为沉浸式语录首页）。

## Impact
- Affected specs: 信息架构（左侧导航）、登录后落地体验、首页视觉与动效、内容展示（语录数据）。
- Affected code: `src/App.tsx` 路由、`src/components/SideNav.tsx` 导航、`src/pages/Home.tsx`（迁移到新路由）、新增首页页面与轮播组件、可能涉及全局样式/动画工具类。

## ADDED Requirements

### Requirement: 沉浸式语录首页
系统 SHALL 在用户登录后提供一个新的首页页面，用于沉浸式展示投资大师经典语录轮播。

#### Scenario: 登录后默认进入首页
- **WHEN** 用户完成登录且未指定 next 跳转地址
- **THEN** 进入根路径 `/` 并看到沉浸式语录首页
- **AND** 页面主体内容聚焦语录，不展示数据表格/图表等高信息密度内容

#### Scenario: 语录轮播展示字段完整
- **WHEN** 首页加载完成
- **THEN** 轮播中每条语录显示：中文、英文、出处、时间（或年份）
- **AND** 语录按“作者（大师）”维度可感知（例如展示姓名/头像占位/标签）

#### Scenario: 轮播交互与节奏
- **WHEN** 用户停留在首页
- **THEN** 语录自动轮播（可暂停或在交互时暂停）
- **AND** 支持手动上一条/下一条
- **AND** 展示当前位置（例如点状/进度条）

#### Scenario: 动效与可访问性
- **WHEN** 用户正常浏览页面
- **THEN** 页面包含细腻但克制的微动效（例如淡入、轻微位移、渐变/高光过渡）
- **AND** 在 `prefers-reduced-motion: reduce` 时动效降低或关闭（仍保证可用）

### Requirement: 首页沉浸式布局
系统 SHALL 让首页的布局更接近“产品详情页”式沉浸体验：大标题/副标题/大留白/暗色背景层次分明，并在桌面与移动端均可良好呈现。

#### Scenario: 全宽沉浸视觉
- **WHEN** 用户进入 `/`
- **THEN** 页面核心区域允许全宽展示（可通过负边距抵消壳层 padding），形成沉浸式主视觉区

## MODIFIED Requirements

### Requirement: 数据面板页路由迁移
系统 SHALL 将原根路径的数据面板页迁移到新路径（例如 `/market`），并保持现有 tab 查询参数逻辑与默认 tab 行为不变。

#### Scenario: 兼容旧链接
- **WHEN** 用户访问旧地址 `/?tab=list|insight|liquidity|lowvol`
- **THEN** 自动跳转到 `/market?tab=...` 并展示对应内容

### Requirement: 左侧导航与路由一致
系统 SHALL 在左侧导航中新增“首页”入口，并保持“数据与方法”等现有入口可用；原先的面板 tabs 入口应改为跳转到迁移后的面板路由。

## REMOVED Requirements
无
