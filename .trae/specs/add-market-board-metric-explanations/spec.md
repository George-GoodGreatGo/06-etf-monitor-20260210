# 为大盘看板增加指标说明 Spec

## Why
用户希望在“沪深市场大盘看板”页面增加对关键指标的详细说明（包含沪深300、EMA20、EMA60、独家流动性指数（3指标）、股债性价比（分位）），以便帮助使用者更好地理解各指标的含义、参数及判断标准。

## What Changes
- 在 `MarketLiquidityPanel.tsx` 页面顶部标题下方区域，替换/扩充原有的单行文字说明。
- 新增对上述5个关键指标的详细说明文案。
- 优化排版（例如使用分点列表和淡色文字），确保信息详实且不干扰主图表的视觉体验。

## Impact
- Affected specs: 首页「沪深市场大盘看板」的指标说明功能
- Affected code:
  - `src/components/MarketLiquidityPanel.tsx`（更新标题下方的说明文案区域）

## ADDED Requirements
### Requirement: 看板指标详细说明
系统 SHALL 在大盘看板页面提供清晰、详细的指标定义与参数说明。

#### Scenario: 页面展示完整的说明内容
- **GIVEN** 用户访问「沪深市场大盘看板」
- **WHEN** 页面加载完成
- **THEN** 用户可以在标题下方看到对以下指标的说明：
  1. **沪深300**：反映中国A股市场整体表现的核心宽基指数。
  2. **EMA20 / EMA60**：分别代表20日和60日指数移动平均线，用于辅助判断短、中长期趋势。
  3. **独家流动性指数（3指标）**：=(成交额分位×换手率分位×北向资金分位)^(1/3)；360日滚动（最少180日）。<30 为机会区，>70 为风险区。
  4. **股债性价比（分位）**：沪深300股息率与10年期国债收益率差值，在过去720天（最少360天）的滚动分位数。
- **AND** 说明文字采用小字号或次级颜色，保持页面布局的整洁与专业感。
