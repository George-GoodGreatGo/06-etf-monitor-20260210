# 沪深市场大盘看板增加“图表/表格”双视图 Spec

## Why
当前大盘看板仅提供图表视图，用户无法逐日核对图表所依赖的原始数据与加工指标（如：独家流动性指数由 3 个原始指标及其分位数计算而来，股债性价比同理）。新增表格视图可提升可解释性、可审计性与数据可信度。

## What Changes
- 在「沪深市场大盘看板」模块内新增视图切换：
  - 视图 1：图表视图（保持现有图表不变）
  - 视图 2：表格视图（逐日展示图表依赖的原始数据与加工指标）
- 扩充大盘看板接口返回的数据字段（或新增一个专用接口），以提供表格视图所需的“原始指标 + 分位数 + 合成指数/分位”：
  - 独家流动性指数（3指标）：成交额、换手率、北向资金（原始值）及其滚动分位数（360 日、最少 180 日），以及指数值（v5）
  - 股债性价比（分位）：沪深300PE（或股息率/收益率）、10Y 国债收益率、股债差值（value）与其滚动分位数（720 日、最少 360 日）
- 表格默认聚焦近期数据（建议默认展示最近 720 个交易日），并提供滚动容器以避免页面过长；表格视图不影响图表视图的交互。

## Impact
- Affected specs: 大盘看板信息呈现方式（新增表格视图）、大盘看板数据可解释性
- Affected code:
  - `src/components/MarketLiquidityPanel.tsx`（视图切换入口与布局）
  - `src/components/charts/MarketLiquidityChart.tsx`（作为图表视图，逻辑不应被破坏）
  - `src/utils/marketApi.ts`（接口类型扩展或新增 fetch）
  - `server/routes/market.ts`（扩充返回字段或新增路由）
  - `server/lib/liquidityV5.ts`（补齐流动性原始值输出）
  - `server/lib/equityBondValue.ts`（补齐股债相关原始值输出）

## ADDED Requirements
### Requirement: 大盘看板双视图切换
系统 SHALL 在大盘看板中提供“图表/表格”两种视图，并可在不重新加载页面的情况下切换。

#### Scenario: 默认展示图表视图
- **WHEN** 用户进入“大盘看板”
- **THEN** 默认展示“图表视图”（与现有保持一致）

#### Scenario: 切换到表格视图
- **WHEN** 用户切换到“表格视图”
- **THEN** 展示逐日数据表格（见下述字段要求）
- **AND** 不影响后续返回图表视图时的图表状态（例如均线开关、BOLL 开关、面板显示/隐藏等保持不变）

### Requirement: 表格视图字段与口径
系统 SHALL 在表格视图中逐日展示“原始数据 + 分位数 + 合成指标”，并保证口径与图表一致。

#### Scenario: 流动性指标逐日展示
- **GIVEN** 独家流动性指数（3指标）= (成交额分位 × 换手率分位 × 北向资金分位)^(1/3)，分位数为 360 日滚动（最少 180 日）
- **WHEN** 用户查看表格视图某一交易日
- **THEN** 该日应展示：
  - 日期
  - 沪深300收盘价（close，供图表主线/均线/BOLL 计算使用）
  - 成交额（沪市+深市，原始值）与成交额分位（amountPct）
  - 换手率（沪深平均，原始值）与换手率分位（trPct）
  - 北向资金（north_money，原始值）与北向资金分位（northPct）
  - 独家流动性指数值（v5）

#### Scenario: 股债性价比逐日展示
- **GIVEN** 股债性价比 value = 1/沪深300PE - 10Y国债收益率（按现有实现口径）
- **AND** 股债性价比分位 pct 为 720 日滚动分位（最少 360 日）
- **WHEN** 用户查看表格视图某一交易日
- **THEN** 该日应展示：
  - 沪深300PE（pe）与/或 股息率（earningsYield=1/pe）
  - 10Y 国债收益率（yield10yPct 或 yield10y）
  - 股债性价比 value
  - 股债性价比（分位）pct

### Requirement: 缺失值与对齐策略可视化
系统 SHALL 在表格视图中对缺失值进行安全展示（例如显示为 “—”），且不因缺失值导致渲染报错。

#### Scenario: 数据缺失
- **WHEN** 某日任一原始字段或分位数缺失
- **THEN** 表格对应单元格展示为缺失值（—）
- **AND** 不影响其它列正常展示
