# 三联动图表对标大盘看板 UI Spec

## Why
当前市场风格 RPS 自定义查询页虽然已经具备“主图 + 2 副图”和三图联动能力，但图表区仍保留独立区块感，标题、hover 字样和信息组织方式与“大盘看板”存在明显差异。用户希望三联动图表在视觉层级和交互文案上像素级对标“大盘看板”，以获得一致的阅读体验。

## What Changes
- 将自定义查询三联动图表区从“3 个分离区块”进一步收敛为与“大盘看板”一致的“主图 + 2 副图”视觉结构
- 对齐三张图的标题排版、区块间距、容器边框、背景层级和分隔方式
- 对齐 hover 期间的日期字样、指标字样、信息排列顺序和呈现位置
- 对齐图表顶部摘要与辅助文案风格，避免出现仅在自定义查询页存在的特有措辞
- 保留现有三图共享可见范围、十字光标、hover 日期和拖拽缩放同步能力

## Impact
- Affected specs: 市场风格 RPS 自定义查询图表展示、图表 hover 联动、图表容器视觉规范
- Affected code: `client/src/features/market-rps` 下自定义查询图表组件、图表头部摘要组件、相关样式与 mock 验收页面

## ADDED Requirements
### Requirement: 自定义查询三联动图表视觉结构对标大盘看板
系统 SHALL 让市场风格 RPS 自定义查询页的三联动图表在视觉结构上采用与“大盘看板”一致的“主图 + 2 副图”样式，而不是呈现为三个彼此割裂的独立区块。

#### Scenario: 主图与副图视觉结构一致
- **WHEN** 用户打开市场风格 RPS 自定义查询页并查看三联动图表
- **THEN** 顶部主图与下方两个副图的容器层级、标题区组织、区块间距和分隔方式应与“大盘看板”保持一致的阅读节奏
- **THEN** 三张图不应再呈现出当前“各自成卡片”的独立区块感

### Requirement: 自定义查询图表标题与 hover 字样对标大盘看板
系统 SHALL 让自定义查询三联动图表的标题、hover 日期字样、指标标签和摘要文案与“大盘看板”采用同一套展示规则。

#### Scenario: hover 任意图表时文案一致
- **WHEN** 用户 hover 主图或任一副图
- **THEN** 三图联动展示的日期、指标名称、数值标签和辅助字样应与“大盘看板”使用一致的命名风格、排列顺序和视觉位置
- **THEN** 不应保留仅服务于当前自定义查询页的独有 hover 文案样式，除非该信息为业务必需且大盘看板不存在等价表达

## MODIFIED Requirements
### Requirement: 自定义查询三联动图表布局与信息展示
系统 SHALL 在保留三图共享可见范围、十字光标、hover 日期、拖拽缩放同步和严格 X 轴对齐的前提下，将图表区的 UI 样式、标题层级和 hover 信息展示统一对标“大盘看板”的主图加副图实现。

#### Scenario: 样式升级后仍保持联动能力
- **WHEN** 用户切换 ETF、拖拽缩放图表或 hover 任意图表
- **THEN** 三图仍保持现有联动行为
- **THEN** 图表标题、摘要和 hover 信息展示应继续符合“大盘看板”的统一样式规范

## REMOVED Requirements
### Requirement: 三图区块允许保留独立卡片风格
**Reason**: 用户已明确要求对标“大盘看板”，当前独立卡片式三图区块会破坏统一的阅读体验。
**Migration**: 将现有自定义查询图表容器、标题区和 hover 展示逐项替换为参考“大盘看板”的对应样式与文案组织方式。
