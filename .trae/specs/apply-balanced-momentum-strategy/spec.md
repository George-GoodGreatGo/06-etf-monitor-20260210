# 动量分析推荐平衡版策略 Spec

## Why
当前“动量分析”页面的买卖箭头仍使用最简版“绿转黄买、黄转绿卖”，在部分 ETF 上会反复触发，带来较高摩擦成本。需要将已验证更平衡的信号规则落实到页面中，并让用户可以在图上快速理解每个买卖点为何触发。

## What Changes
- 将“动量分析”主图买卖箭头逻辑升级为“推荐平衡版”策略
- 保持“买入只能发生在前复权价格 >= SMA250 的上升通道”这一硬约束
- 在页面上新增“推荐平衡版”策略说明，明确买入、卖出与辅助指标的判定口径
- 为每个买卖点提供 hover 原因展示，用户悬停到箭头时可查看触发原因
- 优化信号说明与 hover 文案的组织方式，确保页面交互简洁、信息清晰可查

## Impact
- Affected specs: `动量分析主图信号表达`, `动量分析页面说明`, `主图 hover 信号解释`
- Affected code: `src/components/charts/RpsCustomQueryCharts.tsx`, `src/components/RpsStylePanel.tsx`, 动量分析信号生成与 hover 信息链路

## ADDED Requirements
### Requirement: 动量分析主图支持推荐平衡版买入规则
系统 SHALL 在“动量分析”主图中按推荐平衡版策略识别买入箭头，并且买入信号只能在上升通道内触发。

#### Scenario: 满足推荐平衡版买入条件时显示买入箭头
- **WHEN** 某交易日对应的价格线相对前一交易日由绿色切换为黄色
- **AND** 该交易日的前复权价格大于或等于 `SMA250`
- **AND** 该交易日的前复权价格大于或等于 `SMA20`
- **AND** 该交易日的 `SMA60` 大于或等于 `SMA250`
- **THEN** 系统在该交易日价格点下方显示红色向上箭头
- **AND** 该箭头表示“推荐平衡版买入信号”
- **AND** 同一交易日不得重复绘制多个买入箭头

#### Scenario: 非上升通道下禁止买入
- **WHEN** 某交易日价格线由绿色切换为黄色
- **AND** 该交易日的前复权价格低于 `SMA250`
- **THEN** 系统不得显示买入箭头
- **AND** 页面不得将该交易日解释为可执行买入点

### Requirement: 动量分析主图支持推荐平衡版卖出规则
系统 SHALL 在“动量分析”主图中按推荐平衡版策略识别卖出箭头，以减少单纯颜色切换导致的噪声卖点。

#### Scenario: 满足推荐平衡版卖出条件时显示卖出箭头
- **WHEN** 某交易日对应的价格线相对前一交易日由黄色切换为绿色
- **AND** 以下条件至少满足一项：前复权价格低于 `SMA20`、`MACD Hist` 小于 `0`、`RSI(14)` 小于 `50`
- **THEN** 系统在该交易日价格点上方显示绿色向下箭头
- **AND** 该箭头表示“推荐平衡版卖出信号”
- **AND** 同一交易日不得重复绘制多个卖出箭头

#### Scenario: 仅黄转绿但未满足确认条件时不显示卖出箭头
- **WHEN** 某交易日对应的价格线相对前一交易日由黄色切换为绿色
- **AND** 该交易日同时不满足“价格低于 `SMA20`”“`MACD Hist < 0`”“`RSI(14) < 50`”
- **THEN** 系统不得显示卖出箭头
- **AND** 页面不得将该交易日解释为推荐平衡版卖出点

### Requirement: 页面展示推荐平衡版策略说明
系统 SHALL 在“动量分析”页面中提供清晰、简洁的推荐平衡版策略说明，帮助用户理解信号来源。

#### Scenario: 用户查看策略说明
- **WHEN** 用户进入“动量分析”页面并查看主图区块附近的说明内容
- **THEN** 可以看到“推荐平衡版”策略名称
- **AND** 可以看到买入规则、卖出规则和上升通道限制的简明说明
- **AND** 可以看到 `SMA20`、`SMA60`、`SMA250`、`MACD Hist`、`RSI(14)` 在策略中的作用说明
- **AND** 说明文案应保持简洁，不遮挡图表主交互区域

### Requirement: 买卖点 hover 展示触发原因
系统 SHALL 在用户 hover 到买卖箭头时展示该信号的触发原因，便于复盘核对。

#### Scenario: Hover 买入箭头时查看买入原因
- **WHEN** 用户将鼠标悬停在某个买入箭头上
- **THEN** hover 信息中显示该交易日为“推荐平衡版买入”
- **AND** 展示至少以下原因项：`绿 -> 黄`、`价格 >= SMA250`、`价格 >= SMA20`、`SMA60 >= SMA250`
- **AND** 原因展示应与该交易日的数值 hover 信息保持日期一致

#### Scenario: Hover 卖出箭头时查看卖出原因
- **WHEN** 用户将鼠标悬停在某个卖出箭头上
- **THEN** hover 信息中显示该交易日为“推荐平衡版卖出”
- **AND** 展示 `黄 -> 绿`
- **AND** 展示实际命中的卖出确认原因项，例如 `价格 < SMA20`、`MACD Hist < 0`、`RSI(14) < 50`
- **AND** 未命中的原因项不得被误展示为已触发

#### Scenario: Hover 非箭头位置时保持信息简洁
- **WHEN** 用户 hover 在普通价格点或其他图表区域而非买卖箭头上
- **THEN** 页面继续展示常规日期与指标信息
- **AND** 不额外弹出冗余的策略原因说明

## MODIFIED Requirements
### Requirement: 动量分析主图买卖信号标记
系统 SHALL 将现有“绿转黄买、黄转绿卖”的基础箭头逻辑升级为“推荐平衡版”策略，并继续保持与主图价格线、均线、放量圆点、hover、十字光标和可见范围同步机制兼容。

#### Scenario: 推荐平衡版信号替代旧箭头口径
- **WHEN** 用户在“动量分析”主图查看任意 ETF 的买卖箭头
- **THEN** 页面使用推荐平衡版规则而非旧版最简规则
- **AND** 图上的箭头数量应相对旧版更克制，减少噪声信号
- **AND** 图表缩放、平移和联动行为保持正常

### Requirement: 动量分析主图图例说明
系统 SHALL 在主图附近的图例或说明文案中，完整说明推荐平衡版箭头、价格颜色分段和放量圆点的含义。

#### Scenario: 用户阅读主图图例
- **WHEN** 用户查看主图标题下方或图表徽标中的说明
- **THEN** 可以看到价格颜色分段规则
- **AND** 可以看到放量圆点的含义
- **AND** 可以看到推荐平衡版买入箭头与卖出箭头的含义
- **AND** 可以看到卖出箭头需要额外确认条件这一事实

## REMOVED Requirements
### Requirement: 旧版最简买卖箭头口径
**Reason**: 仅使用“绿转黄买、黄转绿卖”会在部分 ETF 上产生过多往返信号，难以满足降低摩擦成本的目标。  
**Migration**: 原有箭头展示入口保留，但信号判定逻辑切换为推荐平衡版；用户通过新图例和 hover 原因理解变化后的口径。
