# 低波红利与价值择时10Y回退策略复用 Spec

## Why
低波红利与价值择时模块都依赖 10 年期国债收益率，当前在网络抖动场景下仍可能受单源超时影响。  
大盘看板已验证“受控重试 + 替代源回退”可提升稳定性，需要以最小改动将该实践复用到这两个模块。

## What Changes
- 评估并统一低波红利、价值择时的 10Y 拉取入口，复用现有 Chinamoney 主源 + Baostock 回退能力。
- 对两个模块补齐受控重试预算与快速降级，避免单次任务被 10Y 拉取长时间阻塞。
- 为两个模块补齐 `meta/notes` 或日志字段，明确主源、fallback 是否触发、失败摘要。
- 保持既有“失败不发布新 run / 不写入推测值 / 沿用上次可见结果”策略不变。

## Impact
- Affected specs: 低波红利夜间刷新稳定性、价值择时刷新稳定性、跨模块数据源容灾一致性
- Affected code: 低波红利刷新脚本、价值择时刷新脚本、10Y 拉取公共库与日志/元信息写入

## ADDED Requirements
### Requirement: 低波红利与价值择时支持10Y替代源回退
系统 SHALL 在低波红利与价值择时模块中，当 Chinamoney 超时或失败时自动回退到 Baostock 获取 10Y，并继续执行可校验流程。

#### Scenario: 主源失败但替代源可用
- **WHEN** 两模块任一任务中 Chinamoney 失败
- **THEN** 自动切换 Baostock，任务不因 10Y 单点失败而中断

#### Scenario: 主源与替代源均失败
- **WHEN** 两个数据源均不可用
- **THEN** 模块遵循原有发布保护，不发布不完整新结果，并输出可定位原因

## MODIFIED Requirements
### Requirement: 两模块10Y拉取稳定性策略
系统 SHALL 将两模块的 10Y 拉取策略统一为“主源优先 + 受控重试预算 + 回退源降级 + 可观测日志”，并保持数据口径一致。

## REMOVED Requirements
### Requirement: 模块内各自分散的10Y重试与降级实现
**Reason**: 分散实现难以统一稳定性策略与观测字段，增加维护成本。  
**Migration**: 统一复用公共 10Y 拉取能力（含 fallback），模块仅保留业务侧发布保护与最小适配逻辑。
