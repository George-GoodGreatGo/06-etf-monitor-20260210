# Optimize List Page UI Spec

## Why
用户反馈列表页（Top100/Top200 ETF）的整体配色太过黑，尤其是表单（表格）的背景太黑，不利于信息辨别。需要在维持暗黑风格的前提下，对列表页的 UI 样式进行调优，提升数据的可读性和视觉层次感。

## What Changes
- **表格背景与边框：** 
  - 减弱表格整体背景的黑色深度，从原本带有透明度的纯黑背景 `bg-[rgba(255,255,255,0.02)]` 调整为稍亮一点的深蓝/灰蓝背景（如 `#0F172A` / slate-900）。
  - 边框颜色从 `border-[rgba(255,255,255,0.08)]` 调整为清晰的细实线（如 `#1E293B` / slate-800）。
- **表头（Thead）：** 
  - 表头背景从 `bg-[rgba(255,255,255,0.03)]` 调整为更深一点但区分度更好的背景（如 `#0B1120`）。
  - 排序表头的交互背景及字体颜色进行微调，使用 Slate 色系（如 `#94A3B8` -> `#E2E8F0`）。
- **表格行与文字（Tbody）：**
  - 分割线颜色调整为 `#1E293B`。
  - 行 hover 效果从 `hover:bg-[rgba(255,255,255,0.02)]` 调整为更明显的 `hover:bg-[#1E293B]`。
  - 文本颜色（代码、名称、数据值）向 Slate 色系靠拢，增加对比度：灰色说明文字变亮（如 `#64748B`），数据文字（如 `turnover`）变白（如 `#F8FAFC`）。
  - 百分比涨跌幅的红绿颜色微调，使其在暗黑模式下更加明亮清晰（如 `#F87171` 替代暗红，`#34D399` 替代暗绿）。
- **搜索与过滤器（Top100FilterBar）：**
  - 输入框与按钮的背景及边框同步更新为 Slate 色系，去除了繁杂的 rgba 透明度写法，提升界面的质感与一致性。
- **页面通用文案：**
  - 将 `Home.tsx` 中一些次要文案的颜色从过暗的 `#9CA3AF` 提亮至 `#94A3B8`。

## Impact
- Affected specs: 首页列表视图。
- Affected code:
  - `src/components/Top100Table.tsx` (表格核心样式)
  - `src/components/SortableTh.tsx` (表头排序样式)
  - `src/components/Top100FilterBar.tsx` (顶部搜索与重置样式)
  - `src/pages/Home.tsx` (外层文案样式)

## ADDED Requirements
### Requirement: 提升暗黑模式下的可读性
系统 SHALL 在保持整体暗黑风格的同时，使用更高对比度的文本颜色、更清晰的模块分割线以及更柔和的背景色阶（如 Tailwind 的 Slate 色系）来渲染列表数据。

#### Scenario: 用户浏览数据
- **WHEN** 用户在首页列表页查看 ETF 数据
- **THEN** 表格不应该是死黑一片，而是具有层次感，表头、数据行、搜索框之间有明显的区分。涨跌幅颜色明亮且容易辨认。
