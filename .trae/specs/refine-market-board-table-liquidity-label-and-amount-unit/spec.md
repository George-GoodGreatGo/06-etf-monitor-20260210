# 大盘看板表格口径与文案统一 Spec

## Why
当前大盘看板表格中，“独家流动性指数（5年分位）”列在数值旁附带“样本不足”字样，影响快速扫读。  
同时“成交额（沪+深,千元）”的展示单位与用户阅读习惯不一致，需要统一到“亿元”并前后端同口径。

## What Changes
- 调整表格列文案：去掉“独家流动性指数（5年分位）”中的“样本不足”字样展示，不改变数值本身。
- 调整成交额列标题为“成交额（沪+深，亿元）”。
- 在落表阶段将成交额统一换算为“亿元”并持久化，前后端都基于“亿元”口径读取与展示。
- 为历史/缓存数据增加兼容策略，避免新旧单位混用导致误读。

## Impact
- Affected specs: 大盘看板表格视图、市场流动性数据口径、数据发布元信息说明
- Affected code: 市场数据落表链路、市场流动性 API、表格列定义与格式化逻辑

## ADDED Requirements
### Requirement: 成交额单位在落表阶段统一为亿元
系统 SHALL 在写入大盘看板数据时将“沪+深成交额”统一转换为“亿元”单位并存储，API 与前端不再做二次单位换算。

#### Scenario: 新数据发布成功
- **WHEN** 夜间任务生成并写入新的大盘看板 run
- **THEN** 成交额字段以“亿元”为单位落表，并在 API 返回与表格展示中保持一致

#### Scenario: 读取历史可见 run
- **WHEN** 前端请求当前可见 run 的表格数据
- **THEN** 不出现“千元/亿元”混用，列标题与数值量纲一致

## MODIFIED Requirements
### Requirement: 表格中流动性分位列的可读性
系统 SHALL 在“独家流动性指数（5年分位）”列仅展示可读数值，不在单元格内追加“样本不足”字样；当样本不足时仅保留数值展示不受干扰。

## REMOVED Requirements
### Requirement: 在流动性分位列内直接拼接“样本不足”文案
**Reason**: 该文案会干扰表格横向比读，降低数值信息密度。  
**Migration**: 移除单元格拼接逻辑；如需保留提示，改为非侵入式说明（例如列说明或悬浮提示），但不进入数值正文。
