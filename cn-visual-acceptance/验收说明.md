# A股市场风格总览 UI 验收

日期：2026-10-20。此次仅本地修改，未提交、推送或部署。

## 修改内容

- 顶部单一动量概览，只有最高 Score 使用大数字，走强与走弱名单自然换行。
- 截面与趋势采用低对比底色、细边框、8px圆角；表格保留七列与原精度，数值右对齐。
- 趋势标题与分段视图同排，时间次级、标的独立一行，窄屏自然换行。
- 成交额移到趋势后、方法前；九个可选择标的在手机两列展示，完整名称不截断。
- 方法默认折叠，保留原文并补充移入的百分位说明；风险与异常提示仍就近显示。
- 将A股浮动模块导航改为页面内锚点，保留原id，消除手机遮挡；共享导航不改。
- A股图例精简，但原540px图表高度保留；新增默认关闭的高度保护参数，
  不改变美股或自定义页面的默认配置。

## 业务保护

九标的、默认159915/512890、000300基准、红涨绿跌、±0.20pp阈值、
百分位P10/P90、252样本、复权与交易日规则未变。
API、缓存、数据库、Action与策略逻辑无修改，不需要SQL。
成交额仍为独立日期与口径，不与动量快照强制同步。

## 验收条件

使用本机Chromium 1217、生产构建预览 `/market/rps`。
历史为2020-01-01至2026-10-19的合成行情，使用现有计算函数生成指标；
国证成长100仅180个价格点，用于样本不足压力测试。
登录、动量接口与成交额接口均由浏览器路由模拟，不是Supabase真实数据或生产认证。
真实快照验收尚未完成；Safari、实际手机触控和屏幕阅读器未覆盖。

## 已验证

- 1440、1024、390、360px，九行截面与九个成交额标的，无整页横向溢出。
- 三个视图、五个时间范围、默认选择、单标的开关、成交额选择、
  图表悬停、滚轮及拖动操作，键盘Enter展开方法。
- 模拟缺历史时按钮禁用；样本不足保持独立标签。
- 模拟过期、备用、读取提示、空截面、接口502错误均有明确提示。
- 浏览器没有新增pageerror。
- 构建、类型检查、A股与美股测试、美股刷新测试、性能缓存测试、
  成交额测试、服务端编译入口、改动文件ESLint与diff格式检查通过。
- 共享组件仅条件样式和默认关闭参数变更；其他页面未做完整浏览器回归。
