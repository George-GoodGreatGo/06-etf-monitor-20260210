入口 `/market/rps`，读取接口 `/api/rps/cn-panel`，沿用登录权限。
仅总览改用沪深300价格指数（000300）；自定义动量分析、策略信号及原 RPS
发布任务仍用 H30269，不修改既有策略历史或仓位规则。

动量截面、历史趋势及成交额追踪统一使用九个标的：
159915、588000、513180、512050、560010、159259、159967、159263、512890。
三个模块共用标的与名称配置，均不展示510300，成交额追踪不重复512890。
512890红利低波ETF华泰柏瑞作为价值类参考，同时参与截面排名和全部指标计算。
趋势的百分位、Score及起点归一三个视图均采用此配置，
基准仍为000300；默认仅选中159915与512890。
截面新增“冷热区域”：自身历史百分位≤10为过冷区，≥90为过热区，
10到90之间为其它；缺行情或样本不足时显示“暂无有效百分位”，不误判为其它。
512890只复用现有RPS快照中的前复权价格，重新按沪深300指数计算，
不采用旧基准Score。快照采集与读取列表现已补充512890（原来仅有名称配置，
并未采集）；首次上线需运行 `Refresh RPS Style Snapshots` 生成包含它的新快照。
无需新增SQL或新的采集任务，原策略配置不变；510300仅从总览展示移除，
旧策略与快照采集仍保留该标的。

## 数据来源

- 基准使用现有 `market_board_point.close`，该字段由大盘看板任务保存沪深300指数点位。
- ETF 使用现有 `rps_style_point.target_close_qfq`，只复用人民币前复权行情，
  丢弃旧基准的 RPS、MA50、Score，完整重算全部相对指标。
- 分别读取各数据源的可用 run，不跨 run 拼接价格；备用 run 在页面提示。
- 无需 SQL 迁移或重发旧 RPS 历史。需要现有大盘看板与 RPS 快照刷新任务持续运行。
- 服务端需要 `SUPABASE_URL` 和 `SUPABASE_ANON_KEY` 或服务端 service role key。
  缺配置、无指数快照或读取失败时返回明确错误，不调用实时行情或生成推测值。
- ETF 读取失败单独提示，不阻断其他标的；统一以指数最新完整交易日为截止日，
  缺当日行情不拿此前交易日参与当前排名。

## 计算

- RPS = ETF 前复权收盘价 / 沪深300指数点位。
- MA50 = 50 个连续有效内地交易日 RPS 的简单均线，前49日 Score 为 null。
- Score = (RPS / MA50 - 1) * 100%，不是收益率或标的间排名。
- 5日变化 = 当日 Score - 5个内地交易日前 Score，单位百分点。
  大于 +0.20 pp 为走强，小于 -0.20 pp 为走弱，其余平稳。
  此死区为展示过滤参数，未通过回测校准，不是交易信号。
- 20日相对收益 = (当日 RPS / 20个内地交易日前 RPS - 1) * 100%。
- 上海时区15:30前不使用当日行情。实际指数日期作为内地交易日历，
  不填周末及节假日，也不向前填补ETF缺失行情；缺失后重新预热50日均线。
- 各ETF单独计算，保留上市后的可用历史，不拼接指数或其他ETF历史。
- 沪深300指数自身 Score 恒为0且不参与排名；510300不在总览展示，
  仍保留于旧策略与快照采集列表，避免改变已有策略行为。

## 历史百分位

复用美股模块的五个日历年、逐日因果中间排名计算。每个时点只比较自身此前
有效 Score，排除当天与未来，至少252个此前样本。百分位 =
100 * (小于当前值的样本数 + 0.5 * 相等样本数) / 样本总数。
样本不足不画百分位、不填50。先用完整历史计算，再裁剪显示区间；
切换时间范围或其他标的开关不影响百分位。

默认显示0-100百分位，>=90为过热区，<=10为过冷区。Score多标的图不共用
冷热阈值；单标的满足252个历史样本时使用自身最新时点P10/P90，底色仅供
当前参考，不表示历史可得阈值，不能直接用于回测。

## A股解释限制

000300是价格指数，不计现金分红；ETF前复权价格有分红调整，因此不是严格
同口径的总回报超额收益。513180为内地上市跨市场ETF，场内人民币价格含汇率、
折溢价、港股休市影响。涨跌停、停牌及流动性限制可能延续极端动量。
高百分位不代表上涨，过热或过冷不意味着立即反转或可成交。

保留原成交额追踪，按各ETF独立交易日统计，页面提示成交额与动量日期可能不同。
取消总览的进攻/防守模式和主攻仓位展示，避免将相对动量读成交易建议。
