# 市场风格页面 UI 优化复盘与 A 股迁移指南

> 本文依据用户认可的“美股市场风格”最终本地版本整理。
> 用途：指导后续“市场风格RPS-总览”的 UI 优化，不是计算或数据架构变更方案。

## 1. 这次做对了什么

核心不是“少放内容”，而是：**信息有归属，数字有主次，标题不抢空间，边界不抢注意力。**

最终采用深色、低对比、紧凑的行情工作台。以数据和曲线作为视觉重点，不引入摄影、营销横幅、装饰渐变或动画。

| 做对的决策 | 为什么有效 | 后续复用方式 |
| --- | --- | --- |
| 先按任务分组，再减轻外观 | 用户能区分数据状态、当前表现、历史趋势 | 每个区域只有一个主要职责 |
| 摘要独立为顶部动量概览 | 先回答“谁最强、谁走强、谁走弱”，再进入明细 | 放在数据工具栏下方，不在表格内重复 |
| 只放大关键数字 | Score 最高数值成为概览焦点，其他信息保持辅助地位 | 不把所有摘要都做成等权大数字卡 |
| 标题按工作区用途布局 | 减少反复出现的“大标题、说明、分割线、留白” | 概览用小标签，表格标题贴近数据，趋势标题与控件同排 |
| 弱边界保留区块归属 | 没有散乱感，也没有厚重的卡片堆叠感 | 底色负责分组，细边线仅补充边界 |
| 数值列右对齐、等宽数字 | 更容易纵向比较大小、符号和小数位 | Score 加粗，辅助收益弱化，状态与数值分开 |
| 控件分清主次与作用范围 | 用户知道切换的是视图、时间还是标的 | 视图为分段控件，时间次级，标的独立一行 |
| 方法说明折叠、风险说明就近保留 | 主工作区清爽，但业务解释没有丢失 | 短解释在图旁，完整方法按需展开 |
| 用实际截图迭代 | 暴露标题高度、控件换行和手机溢出问题 | 功能测试与视觉验收分开进行 |

## 2. 必须保留的迭代教训

### 2.1 不要把“克制”理解成取消所有区块

第一轮减少卡片后，摘要、表格、控件、说明缺少明确归属，用户反馈“有点散乱”。
因此，需要保留业务区域的视觉边界，而不是恢复成很多独立小卡片。

### 2.2 不要把“区块清楚”理解成重复大标题卡片

加入面板后，每块都使用较大标题、较多留白和完整外框，显得机械且占高度。
最终通过不同标题位置、紧凑字号、减弱边线与缩小圆角解决。

### 2.3 顶部概览是行情摘要，不是营销 Hero

用户明确要求将摘要独立到顶部，但它的职责仍是监控与判断。
不添加口号、插画、大面积空白或背景效果；关键数字是视觉锚点。

### 2.4 压缩的是展示开销，不是数据可用性

不要删除列、缩小图表、隐藏异常状态，或把点击区域压到难以操作。
最终版本保留全部指标、原图表高度与交互，只减少标题区和重复分割的留白。

## 3. 建议的信息结构

```text
页面名称、基准与价格口径                 现有数据操作
交易日、数据状态                         任务进度或错误

动量概览（小标签）
Score最高：标的＋突出数值   5日走强标的   5日走弱标的

动量截面                         简短排序与口径提示
完整指标表格

动量趋势  [视图切换]                     [时间范围]
比较标的 [选择控件……]
细分割线
当前视图的一句解释、图例、图表
风险提示                               交互提示

成交金额追踪（A股现有区域，保留业务功能）
紧凑标题、现有操作、表格或图表

▸ A股计算口径与阅读方法
```

成交额属于次级工作区，建议在趋势之后、折叠方法之前；迁移时保留已有锚点与导航能力。
不要为了外观合并不同来源、日期或口径的数据，也不要让方法区插在主工作区之间。

## 4. 可直接参考的视觉参数

以下为美股最终版本的实际参数，不是必须锁死的全站规范。迁移时以 A 股内容长度和现有主题为准。

| 项目 | 当前参数 | 设计目的 |
| --- | --- | --- |
| 主区域间距 | 24px，`space-y-6` | 区域独立，内部紧凑 |
| 概览表面 | `bg-[#101B24]/80`，无外框 | 比正文略突出，不做重卡片 |
| 截面与趋势表面 | `bg-[#0C141B]/70` | 与背景轻微区分 |
| 面板边线 | `border-white/[0.06]` | 弱边界，不抢数据 |
| 面板圆角 | 8px，`rounded-lg` | 减少大圆角卡片感 |
| 面板内边距 | 手机横向16px，桌面20px；纵向12px | 内容紧凑且留有呼吸 |
| 概览标签 | 12px、medium、slate-300；下距8px | 标题不与数字竞争 |
| 截面标题 | 14px、semibold、slate-200；下距4px | 贴近表头，不做独立大标题栏 |
| 趋势标题 | 14px、semibold，与视图控件同排 | 把标题转为操作区的一部分 |
| 概览关键数值 | 30px、semibold、等宽数字 | 一个明确焦点 |
| 表格 | 14px正文、12px表头，单元格 `px-3 py-2.5` | 紧凑但可读 |
| 数值列 | `text-right font-mono tabular-nums` | 支持纵向扫描 |
| 趋势操作区 | 底部6%白色分割线，内部间距8px | 操作与图表分开，不重复加上下框 |
| 方法入口 | 12px、slate-400，默认折叠 | 次要信息按需访问 |

不要机械复制低对比边框到文本、错误提示或焦点环。数据与状态仍须清楚可读。

## 5. 色彩、说明与交互

- 保留现有标的配色，表格色点、选择控件、曲线和图例保持一致。
- 颜色用于业务语义，不给各面板增加不同主题色。
- 美股版用绿/玫红配合方向图标表示走强/走弱，橙/蓝表示过热/过冷。A 股先核对现有约定，不未经确认反转红绿含义。
- 状态同时使用文字或图标，不让用户只能靠颜色理解。
- 普通状态可用文字与细左边线；错误、过期、备用快照、缺历史等警告不能因美化被隐藏。
- 页面只强调一个真正的主要操作。A 股当前是“刷新读取”，不能因美股有“更新市场数据”而新增或暗示远端更新能力。
- 表头可缩短，但单位与定义仍需通过数值单位、简短说明及完整方法提供；`title` 只能作补充，手机与键盘用户不能依赖悬停。
- 每种图表视图保留一句有效解释，详细方法折叠；风险提示在图表旁保留。
- 图例可精简共同定义，不可丢失标的名称、颜色、基准意义或重要样本提示。
- 保留按钮悬停、表格行悬停、选中态、禁用态与可见焦点；尊重减少动画偏好，不新增装饰入场或滚动动画。
- 保留语义标题、`aria-labelledby`、`aria-pressed`、状态播报和表格滚动区域键盘聚焦。

## 6. A 股迁移：具体修改范围与保护项

### 6.1 修改位置

| 文件 | 作用 | 建议范围 |
| --- | --- | --- |
| `src/pages/MarketRpsOverview.tsx` | 总览入口与组件组合 | 保持入口、面包屑和组件职责，按需调整业务区顺序 |
| `src/components/CnMarketStylePanel.tsx` | 数据状态、摘要、截面、趋势、A股方法 | 主要布局与样式修改位置 |
| `src/components/RpsStylePanel.tsx` | 总览的成交额区域，同时服务其他页面 | 只调整 `page="turnover"` 对应分支或新增默认关闭的展示参数 |
| `src/components/charts/RpsStyleChart.tsx` | 共用图表 | 优先复用已有 `compactLegend`，避免改变所有页面默认配置 |
| `docs/cn-market-style.md` | A股业务口径 | 实施前核对，作为不可随意改动的规则依据 |

美股视觉参考：`src/pages/UsMarketStyle.tsx`。
不要全局替换共享组件的圆角、颜色、标题或图表高度，否则可能影响自定义动量分析与其他页面。

### 6.2 不能照搬的美股业务规则

- A 股总览基准为沪深300价格指数 `000300`，不是 VOO，也不要改动旧策略使用的 `H30269`。
- A 股当前默认选择为 `159915` 和 `512890`，不是 VYM 与 VGT。
- 总览现有九个标的全部保留：159915、588000、513180、512050、560010、159259、159967、159263、512890。
- 不重新加入总览已移除的510300，也不删除旧策略与采集中的510300。
- A 股走强/走弱展示阈值为 ±0.20pp，美股为 ±0.10pp；UI 优化不修改阈值。
- 保留人民币前复权价格、上海交易日、15:30完整行情截止、缺失后的均线重新预热、独立计算和数据来源。
- 百分位继续采用现有因果计算：自身此前五年、排除当前与未来、至少252样本；先算完整历史再裁剪。
- 缺行情、样本不足与正常中性状态必须区分。A 股“暂无有效百分位”不得改为“其它”或默认50。
- 保留沪深300价格指数与前复权ETF并非严格总回报同口径的说明，以及513180跨市场、汇率、折溢价、停牌与涨跌停限制。
- 不修改 API、Supabase、GitHub Actions、缓存、数据更新或策略仓位逻辑；本次 UI 迁移不需要新增 SQL。

### 6.3 根据 A 股内容密度适配

A 股有九个标的，代码更长，走强/走弱列表和选择控件可能比美股占空间。
概览沿用“一个主要数值＋两组标的”的结构，但允许自然换行，不截断名单。
手机宽度不足时可以改为纵向两组，不强迫复制美股两列。

趋势标题与视图切换优先同排；不足时自然换行，不靠极小字体或缩小按钮硬塞。
保留原有图表模式的含义，只有名称与实际计算一致时才能改文案。

## 7. 推荐实施步骤

1. 记录 A 股优化前的桌面与手机截图，核对区域、默认值、数据字段与已有交互。
2. 仅调整 `CnMarketStylePanel` 的分组、摘要、表格和标题，不动数据处理。
3. 弱化底色和边框，压缩标题区；保持区域间距，不走回“取消所有边界”的旧路。
4. 将趋势标题与控件整合，精简重复解释，完整方法默认折叠。
5. 统一成交额区域的视觉语言，保留功能、来源和锚点；确保其他 `RpsStylePanel` 页面未受影响。
6. 跑构建、现有相关测试、改动文件 ESLint 和 `git diff --check`。
7. 使用有代表性的真实历史快照验收响应式、长名单、无数据、样本不足、过期与备用快照状态。
8. 对比同尺寸截图，根据实际观感微调；输出验收范围与未覆盖项，不把本地验收说成已上线。

## 8. 验收清单

- [ ] 扫描标题即可理解“状态、概览、截面、趋势、成交额”的职责。
- [ ] 概览只有一个主要视觉焦点，摘要不在表格上方重复。
- [ ] 标题没有重复的大块留白，趋势标题与操作布局紧凑。
- [ ] 区块仍清楚分组，没有过重外框、明显阴影或卡片套卡片。
- [ ] 表格所有列、单位、精度、排序和状态含义不变，数值列右对齐。
- [ ] 在1440、1024、390px宽度验收，并增加更窄尺寸或长内容压力检查。
- [ ] 整页无横向溢出；表格只在自身容器滚动，并有移动端提示。
- [ ] 九个标的完整可用；长名单不截断；原默认选择不变。
- [ ] 原有图表模式、时间范围、标的选择、缩放与提示完整可用。
- [ ] 冷热底色、阈值、图例、基准与百分位含义未被改动。
- [ ] 错误、过期、备用数据、缺历史和样本不足均明确展示。
- [ ] 折叠方法支持键盘，焦点可见，状态不只靠颜色。
- [ ] 共享组件其他页面的默认展示没有回归。
- [ ] 构建与相关测试通过，浏览器无新增运行错误。
- [ ] 如实注明浏览器、快照日期、模拟条件，以及真实触控和Safari是否覆盖。

## 9. 既有证据与参考

美股最终版曾验收1440、1024、390px Chromium视口及图表切换、提示与方法展开。
使用的是截至2026-10-08的本地历史快照，不是线上最新数据或真实手机触控验证。

最后一轮仅调整标题与边界后，同尺寸全页截图高度由1733px降至1578px（桌面），1879px降至1760px（手机）。
这是该快照与布局下的观察结果，不应作为 A 股必须达到的像素目标。
验收记录未报告新增遮挡、文字截断或整页横向溢出。
