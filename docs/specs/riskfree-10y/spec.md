# 中国10年期国债收益率（CN10Y）多数据源稳健获取改造规范

## 背景与目标
- 受网络波动、源站限流与页面结构变更影响，大盘看板、低波机会、价值择时在获取“10年期国债收益率”（CN10Y）时存在偶发获取不到或超时，导致运行失败或沿用旧 run。
- 目标：以稳定、真实为首要原则，统一抽象“CN10Y 风险自由利率”获取层，采用≥3个公开数据源的多源容错与一致性校验，保证在正常交易日实现稳定获取与原子发布。
- 成功标准：
  - 数据层面：在交易日 T+1 夜间刷新链路中，CN10Y获取成功率≥99.9%，值在可信范围且通过一致性校验。
  - 系统层面：获取失败不发布新 run，保留最近 5 次 run；发布链路原子切换；全量重算保持既有策略。

## 改造范围
- 新增统一服务：riskfree10yService（CN10Y 多源聚合器），供大盘看板、低波机会、价值择时三模块共享。
- 统一缓存与发布机制：沿用既有“原子发布 + 5 次回退”的模块化元数据表（meta + point + publish_run）。
- 统一日志与可观测性：详细记录主源/回退源、重试次数、时间预算、偏差校验与最终选择。

## 数据源策略（≥3个公开源）
- 主源（S1）：Chinamoney（CFETS/中国外汇交易中心），从“国债收益率曲线（现券）”页面或公开接口解析10年期点位。
  - 行为：受控超时（connect≤1.5s，read≤1.5s）、幂等重试（最多2次，指数退避），页面结构变化时降级为备用源。
  - 产出：日期（日维）、收益率（年化%）、数据来源指纹（来源名/抓取路径版本）。
- 备源（S2）：Eastmoney 数据中心（公开接口或社区已知可解析端点；亦可通过 AkShare 包装）。
  - 行为：独立超时配置与重试；解析为同口径日度点。
  - 说明：Eastmoney存在动态参数与限流风险，需添加UA/Referer与限速保护。
- 备源（S3）：Sina/TradingEconomics/Investing（择三选二，至少保证三源可用）
  - 推荐优先级：
    - Sina Finance（公开页面的中国10年期国债收益率，轻解析）。
    - TradingEconomics（需免费API key；如未配置则不参与选择），稳定时间序列，供校验。
    - Investing（页面端点变化较频繁，作为兜底备选）。
  - 环境策略：若配置了TE_API_KEY则启用TE；否则使用Sina与Investing实现≥3源。

注：现有记忆已采用“Chinamoney主源 + Baostock回退”，Baostock对债券收益率支持有限，保留其作为网络层兜底（例如代理/镜像），不计入核心取值源。

## 标准化与一致性校验
- 统一口径：
  - 日期：lastMarketDay（交易日日维）；遇节假日按最近交易日对齐。
  - 单位：百分比（如 2.35 表示 2.35% 年化），保留四舍五入至小数点后2位用于展示；落表保留原始小数精度。
  - 字段：value、source、observedAt、notes（包含重试、回退、差异）。
- 一致性选择：
  - 过滤：剔除空值、负值或超出合理范围（0%–10%）；剔除含明显解析错误的离群值。
  - 集成：对通过过滤的各源取“加权中位数”（若无权重则取中位数），并计算与各源的绝对偏差。
  - 阈值：若任一源与集成值偏差≥30bp（0.30%），标记为离群不参与最终值；若仅剩1源，需满足“可信值判定”（历史±300bp窗口且非跳变）。
  - 结果：最终值为中位数或可信单源值；记录参与源及偏差概要。

## 失败处理与发布策略
- 时间预算：单源≤3s，总预算≤6s；超时立即放弃并切换备用源。
- 失败条件：所有源均失败或仅有离群值；此时不发布新 run，沿用上次可见 run（保持真实与稳健，不以旧值回填新日）。
- 原子发布：写入point表后进行整批校验，仅校验通过方可通过meta发布新run；保留最近5个run用于快速回退。
- 记录：meta.notes记录主源/回退触发、参与源列表、离群剔除与最终采用值。

## 缓存与快照
- 读取缓存：CN10Y按自然日缓存TTL≈24小时；服务端区分calcVersion以隔离旧口径快照。
- 快照保留：仅保留日维最新值；后端历史查询通过源站或历史落表获取，不在高频链路重复抓取。

## 接口契约
- REST：GET /riskfree/10y?date=YYYY-MM-DD
  - 200：{ value:number, unit:"pct", source:string, observedAt:string, status:"ok", notes?:string }
  - 206：{ status:"partial", value:number, sourcesUsed:string[], warnings:string[] }
  - 503：{ status:"error", code:string, msg:string }
- SDK：riskfree10yService.get(date?)，默认最近交易日；返回同结构对象。

## 可观测性与告警
- 指标：fetch_success_ratio、median_deviation_bp、timeout_ratio、fallback_trigger_ratio。
- 告警：交易日晚间获取失败或偏差>30bp频发时触发提醒；异常阈值可通过配置中心调整。

## 安全与合规
- 不保存或公开站点的敏感令牌；TradingEconomics等需要key的源为可选。
- 抓取遵循合理频率与缓存策略，避免对源站产生不必要负载。

## 回归测试与验收
- 单元测试：各源解析器的正常/异常/结构变更模拟；时间预算与重试策略。
- 集成测试：多源并发抓取与中位数选择；离群剔除与阈值校验。
- 端到端：在T+1夜间任务中拉取最近90个交易日，验证成功率、偏差分布与发布原子性。
- 验收标准：满足成功标准与日志/告警完整；三模块读取统一服务后无行为回归差异。

## 兼容与迁移
- 三模块统一改读riskfree10yService；旧直连抓取逻辑保留一版作为紧急兜底开关（默认关闭）。
- 不改变前端展示与分析逻辑，仅提升数据层稳健性。
