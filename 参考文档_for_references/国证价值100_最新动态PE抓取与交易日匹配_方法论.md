# 国证价值100（980081 / CNIV100）最新动态PE抓取与交易日匹配方法论（基于官网公开接口）

> 目标：通过国证指数官网的公开接口抓取 **国证价值100指数（indexCode=980081）** 的 **最新动态市盈率（PE(滚动/TTM)，下文简称“动态PE”）**，并为该PE记录匹配一个明确的“交易日（trade_date）”。

---

## 1. 背景与口径说明

### 1.1 动态PE是什么？
- 官网接口字段 `peDynamic` 对应 **PE(滚动/TTM)**，通常可理解为：  
  **PE(TTM) = ∑成分股总市值 / ∑成分股归母净利润(TTM)**（汇总法/加权口径）。
- 该口径与市场上“每日估值”常用口径一致：相对“静态PE（年报口径）”，TTM更贴近当前盈利滚动变化。

### 1.2 为什么需要“交易日匹配”？
用于每日落库、回测或监控时，必须把抓取到的“快照值”绑定到某个日期；否则无法形成时间序列或与行情对齐。

### 1.3 关键结论（方法论核心）
1. **动态PE的来源接口本身不返回“估值日期/交易日”字段**，因此无法仅靠该接口“证明”日期。
2. 但可以通过官网另一个接口获取该指数的 **最近交易日 `lastMarketDay`**，并将动态PE快照 **归因（assign）** 到该日期。  
3. 这是目前在“仅使用官网公开接口”的约束下，最稳健且可工程化的方案。

---

## 2. 使用的官网接口（Endpoints）

### 2.1 动态PE快照接口（包含 peDynamic）
**接口：**
- `GET https://www.cnindex.com.cn/index/running?type=1`

**说明：**
- 返回一个指数列表（按分类 type），其中包含 `peDynamic / peStatic / pb` 等字段。
- 国证价值100在返回列表里可通过 `indexcode == "980081"` 定位。

**字段：**
- `indexcode`：指数代码（如 `980081`）
- `peDynamic`：动态PE（PE(滚动/TTM)）
- `peStatic`：静态PE
- `pb`：市净率
- ⚠️ `sampleshowdate`：此接口返回中通常为 `null`（不提供日期）

### 2.2 最近交易日接口（提供 lastMarketDay）
**接口：**
- `GET https://www.cnindex.com.cn/market/market/getMarketDay?codesValue=980081`

**说明：**
- 返回该指数是否为交易日、最近交易日、最近交易日的上一个交易日等信息。

**字段：**
- `isMarketDy`：今天是否交易日（`1`=是，`0`=否）
- `lastMarketDay`：最近一个交易日（建议作为 `trade_date`）
- `lastUpMarketDay`：最近交易日的上一个交易日

### 2.3（可选）最新行情时间戳接口（辅助校验）
**接口：**
- `GET https://hq.cnindex.com.cn/market/market/getIndexLatestRealTimeData?indexCode=980081`

**说明：**
- 返回行情的时间戳 `timestamp`（毫秒），以及盘中最新点位等。
- 该时间戳代表行情数据更新时刻，不一定等价于“估值计算日”，但可用于排查“抓取时点是否跨日/是否更新到最新交易日”等问题。

## 3. 方法论流程（推荐实现）

### 3.1 流程概览
1. 拉取 **动态PE快照**：`/index/running?type=1` → 找到 `indexcode=980081` 的 `peDynamic`
2. 拉取 **最近交易日**：`/market/market/getMarketDay?codesValue=980081` → 取 `lastMarketDay`
3. 生成一条记录并落库/输出：
   - `index_code = 980081`
   - `trade_date = lastMarketDay`
   - `pe_ttm = peDynamic`
   - `fetched_at = 抓取时刻（本地或UTC）`
4.（可选）拉取行情 `timestamp` 作为辅助字段：
   - `market_ts = timestamp`

### 3.2 数据归因规则（trade_date 如何确定）
**规则：**
- `trade_date := lastMarketDay`

**解释：**
- 因为 `/index/running` 不提供日期，`lastMarketDay` 是官网对该指数“最新交易日”的权威返回；将当期估值快照归因到 `lastMarketDay` 是最一致的工程实践。

### 3.3 异常与边界条件
1. **节假日/周末**
   - `isMarketDy=0` 时，`lastMarketDay` 会指向上一交易日；此时仍使用 `lastMarketDay` 作为 `trade_date`。
2. **收盘后更新延迟**
   - 若你在收盘后立即抓取，PE可能尚未刷新；可以：
     - 延迟到固定时间（例如 18:00~20:00）抓取
     - 或定时重试，直到检测到 `trade_date` 或 `pe_ttm` 发生变化
3. **接口返回缺失/结构变化**
   - 若在 `type=1` 中找不到 `980081`，可降级策略：
     - 遍历 `type=0/1/2/3`（或抓官网页面对应分类），直到找到 `980081`
     - 记录告警并保留原始响应以便排查
4. **跨日问题（凌晨抓取）**
   - 建议用 `lastMarketDay` 固定日期，不用本地日期推断交易日。

## 4. 输出数据结构（建议）

建议每次抓取落一条结构化记录（JSON/表格均可）：

| 字段 | 类型 | 示例 | 含义 |
|---|---|---|---|
| index_code | string | `"980081"` | 指数代码 |
| index_name | string | `"价值100"` | 指数简称（可选） |
| trade_date | string(YYYY-MM-DD) | `"2026-04-13"` | 归因交易日（lastMarketDay） |
| pe_ttm | number | 10.0189 | 动态PE（peDynamic） |
| pe_static | number | 10.1447 | 静态PE（peStatic，可选） |
| pb | number | 1.05 | PB（可选） |
| is_market_day | boolean/int | 1 | 是否交易日（isMarketDy） |
| fetched_at | string | `"2026-04-14T09:30:00+08:00"` | 抓取时刻 |
| market_ts | int | 1776150000000 | 行情时间戳（可选） |
| source | string | `"cnindex"` | 数据源标识 |

## 5. 参考实现

### 5.1 curl 示例
```bash
# 1) PE快照（列表里筛 980081）
curl -s 'https://www.cnindex.com.cn/index/running?type=1'

# 2) 最近交易日
curl -s 'https://www.cnindex.com.cn/market/market/getMarketDay?codesValue=980081'

# 3)（可选）最新行情时间戳
curl -s 'https://hq.cnindex.com.cn/market/market/getIndexLatestRealTimeData?indexCode=980081'
```

### 5.2 Python 示例（最小可用）
```python
import requests
from datetime import datetime, timezone

INDEX_CODE = "980081"

def get_pe_snapshot():
    r = requests.get(
        "https://www.cnindex.com.cn/index/running",
        params={"type": 1},
        timeout=30,
    )
    r.raise_for_status()
    data = r.json()["data"]
    row = next(x for x in data if x.get("indexcode") == INDEX_CODE)
    return row

def get_last_market_day():
    r = requests.get(
        "https://www.cnindex.com.cn/market/market/getMarketDay",
        params={"codesValue": INDEX_CODE},
        timeout=30,
    )
    r.raise_for_status()
    return r.json()["data"][0]

def get_market_ts_optional():
    r = requests.get(
        "https://hq.cnindex.com.cn/market/market/getIndexLatestRealTimeData",
        params={"indexCode": INDEX_CODE},
        timeout=30,
    )
    r.raise_for_status()
    j = r.json()
    # timestamp 在 j["data"]["data"][0][0]
    ts = j["data"]["data"][0][0]
    return ts

pe_row = get_pe_snapshot()
mk = get_last_market_day()

record = {
    "index_code": INDEX_CODE,
    "index_name": pe_row.get("indexname"),
    "trade_date": mk.get("lastMarketDay"),
    "pe_ttm": pe_row.get("peDynamic"),
    "pe_static": pe_row.get("peStatic"),
    "pb": pe_row.get("pb"),
    "is_market_day": mk.get("isMarketDy"),
    "fetched_at": datetime.now().astimezone().isoformat(timespec="seconds"),
    "market_ts": get_market_ts_optional(),
    "source": "cnindex",
}

print(record)
```

## 6. 校验建议（确保“日期匹配”靠谱）

1. **一致性检查**
   - 若 `trade_date` 改变（比如从 `2026-04-13` 变为 `2026-04-14`），PE也通常会随之变化；如果日期变了但 PE 长期不变，可触发告警。
2. **更新时点检查**
   - 每天固定在“收盘后一段时间”采集，例如 18:00 之后。
3. **落库去重**
   - 主键建议用 `(index_code, trade_date)`；同一交易日多次抓取，可保留最新一条或保存多条用于审计。
